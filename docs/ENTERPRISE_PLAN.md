# خطة «BotYalla Enterprise» — منصة تواصل واتساب متكاملة

> أول عميل: **فنادق الفرسان (Alforsan Hotels)** — حجوزات فنادق وعمرة، أرقام سعودية،
> عربي/إنجليزي، ينتقل من منصة منافسة. المرجع البصري: `Screenshot Requiments/`.
> **القاعدة:** نفس القدرات وسهولة الاستخدام بتصميم وهوية BotYalla — لا نسخ لاسم أو شعار أو شاشات منافس.

## القرارات المعتمدة (2026-09-26)
| القرار | الاختيار |
|---|---|
| مكان البناء | **ميزات منصة** تُفتح بباقة **Enterprise** (قاعدة كود واحدة، أي عميل لاحق يستفيد) |
| ترتيب التسليم | **شغله اليومي أولاً**: المراحل 1–4 (~5 أسابيع) ثم الكانفس |
| رقمه الحالي | **رقم تجريبي أولاً** ثم نقل الرقم الرئيسي + الاستيراد في يوم واحد |
| التصميم | **فاتح + داكن بمبدّل** لكل مستخدم (الداكن الحالي يبقى كما هو) |
| الدفع | **كل الخيارات والعميل يختار** — انظر «أوضاع الفوترة» |
| الفريق | **فرق + توجيه محادثات** |
| الاستيراد | جهات الاتصال · القوالب · الفلوهات · سجل المحادثات القديم (بأفضل ما يسمح به المصدر) |
| الموعد | بلا التزام — تقرير تقدّم نهاية كل مرحلة |

## أوضاع الفوترة (الحساب يختار، ويمكن التبديل)
1. **Meta مباشرة** — العميل يضيف بطاقته في Meta Business؛ لا خصم محفظة على رسائله إطلاقاً، ونحصّل الاشتراك فقط.
2. **محفظة بالدولار** — رصيد مسبق بالسنت الصحيح (نفس قاعدة §19: أعداد صحيحة، `_wallet_move`، `WHERE balance >= ?`)، وسعر كل رسالة = سعر Meta **لبلد المستلم وفئة القالب** + هامش المنصة من الإعدادات.
3. **المحفظة الحالية بالجنيه** — كما هي اليوم.
- عمود `currency` على المحفظة والسجل (افتراضي `EGP` — القديم لا يتغيّر). لا تحويل عملة ضمني أبداً.
- الشحن: نفس مسار الإيصال والموافقة (§34) + بوابة أونلاين لاحقاً. الفئة من Meta لا من الفورم (§20) في كل الأوضاع.

## المراحل

### 1) أساس البيانات — جهات الاتصال (CRM) · ~أسبوع
- `contacts` موحّد **لكل حساب** (يدمج `bot_users`/`leads` من كل البوتات، بالهاتف وBSUID) — ترحيل تلقائي للقديم.
- `contact_fields` حقول مخصّصة: Text · Multi-text · Number · Select · Multi-select · Date · Switch · User — مع «نشط» و«إلزامي».
- `tags` + `contact_tags` · **Segments** فلاتر محفوظة (يحتوي/يساوي/قبل/بعد على أي حقل أو وسم أو آخر تفاعل) بعدّ حيّ.
- استيراد CSV/Excel بشاشة **مطابقة أعمدة** + معاينة + تقرير أخطاء؛ تصدير؛ موافقة تسويقية `opted_in` (تحترم §55).
- صفحة Contacts بجدول أعمدة قابلة للتخصيص + بحث + فلترة + عمليات جماعية (وسم/حذف/تصدير).

### 2) تتبّع الرسائل · ~3–4 أيام
- معالجة `statuses` من ويبهوك واتساب: sent → delivered → read → failed + رمز الخطأ (غير موجود على واتساب · حدّ التكرار 131049 · …).
- `message_status` لكل رسالة صادرة (بـ`wamid`) — أساس تحليلات البثّ والـRetarget.

### 3) Broadcast 2.0 · ~1.5 أسبوع
- معالج 3 خطوات: قالب (+ ربط المتغيّرات بحقول جهة الاتصال) → جمهور (Segments) → جدولة (الآن/لاحقاً) + إعادة محاولة ذكية.
- حدّ الإرسال اليومي (Messaging tier) · سياسة الموافقة · إسناد الردود لفريق/موظف.
- جدول الحملات: Recipients / Sent / Delivered / Read / Engaged / Not on WhatsApp / Frequency limit / Failed + **Retarget** (شريحة من «قرأ ولم يرد»…) + تصدير.
- معاينة التكلفة قبل الإرسال بحسب وضع الفوترة. قواعد §19–22 و§38 لا تتغيّر (خصم ذرّي قبل، ردّ ما لم يصل بعد).

### 4) Template Studio · ~أسبوع
- Custom · Product · **Carousel** · **Limited-Time Offer** · Authentication.
- Header: نص/صورة/فيديو/مستند/موقع · متغيّرات مسمّاة · Footer · أزرار: Quick reply · URL · Phone · Coupon · Flow.
- **معاينة واتساب حيّة** بجانب المحرّر + حالة الاعتماد تُزامَن من Meta.

### 5) باني الفلو المرئي · ~3 أسابيع
- كانفس سحب وإفلات (`@xyflow/react`، MIT) + لوحة بطاقات:
  - Ask: Button · List · Text · Number · Email · Date · Phone · Location · URL · File
  - Send: Text · Media · Template · Product · Location · Form
  - Utilities: Condition · Set Variable · Jump to · Delay · Business Hours · Assign to team · AI reply
- **عدّة فلوهات لكل بوت بمشغّلات**: أي رسالة · كلمات محددة · نقرة إعلان (CTX referral) · زر قالب.
- مسودة/نشر بنسخ (`bot_config_versions`) + Sessions / Completed / Dropped + **خريطة التسرّب على الكانفس**.
- المحرّك يصبح رسماً بيانياً؛ الفلوهات الخطية القديمة تُحوَّل تلقائياً ويبقى `chat_state` مصدر الحالة (§ chat_state).

### 6) الصندوق المشترك + أدوات النمو · ~1.5 أسبوع
- **فرق** (حجوزات/شركات/عمرة) + توجيه: من الفلو (بطاقة Assign) · Round-robin · يدوي. حالة المحادثة: مفتوحة/معلّقة/مغلقة.
- ردود جاهزة (Canned) · ملاحظات داخلية · حقول محادثة · لوحة جهة الاتصال بجانب المحادثة.
- Sequences (متابعة تلقائية عند الصمت، تحترم STOP ونافذة 24 ساعة) · Magic Link + QR · ودجت واتساب للموقع · تتبّع إعلانات CTX.

### 7) النمو والإعلانات · ~2 أسبوع
Website widget + Web chat بوكيل AI · Magic link/QR · **CTWA** (أداء الإعلانات · Leads · **CAPI**) · WhatsApp Forms (Flows).

### 8) قنوات إضافية · ~3 أسابيع
Instagram DMs + أتمتة التعليقات · WhatsApp Coexistence · Groups · WhatsApp Calling (وارد/صادر) · AI Voice (آخرها — يحتاج مزوّد اتصالات).

### 9) التجارة والتكاملات · ~2–3 أسابيع
Catalog/Orders/Payments داخل واتساب ببوابات سعودية (Moyasar/Tap/HyperPay) · Google Sheets · Facebook Leads · Zapier/Make · HubSpot/Zoho · سلة/زد/Shopify/WooCommerce · Conversation widget.

> **قائمة القبول التفصيلية لكل بند:** [COMPETITOR_PARITY.md](COMPETITOR_PARITY.md) — مراجعة 172 صفحة من توثيق المنافس.

## ميزات تتفوّق على المنافس
- عربي أولاً RTL حقيقي · مبدّل فاتح/داكن.
- **ذكاء يبني فلو كاملاً من وصف** («بوت حجز عمرة بالباقات والتواريخ») — امتداد لوكيل الإعداد (§30).
- **قالب فنادق**: موسم ← فندق ← نوع غرفة ← تواريخ ← عدد أفراد ← عرض سعر ← تحويل لفريق الحجز.
- ردود AI من قاعدة معرفته (§29) · خريطة تسرّب على الفلو · تكلفة الحملة قبل الإرسال بعملته.

## خطة الانتقال (Cutover)
1. **رقم تجريبي** يُربط بالتسجيل بضغطة (§57) — نبني ونختبر عليه كل المراحل.
2. **جهات الاتصال**: CSV من Contacts → Export عندهم ← شاشة المطابقة (الأسماء · الهاتف · الوسوم · الحقول المخصّصة · الموافقة).
3. **القوالب**: محفوظة على WABA الخاص به لا عند المنافس ← تُسحب تلقائياً عند ربط الرقم.
4. **الفلوهات** (5): لا تُصدَّر من المنافس ← نعيد بناءها على الكانفس (يدوياً أو بالذكاء من وصفها) وتُراجَع معه.
5. **سجل المحادثات القديم** — ثلاث طبقات بصراحة:
   - تقارير الرسائل عندهم تُصدَّر **بلا نص الرسالة** (تاريخ/حالة/قالب، 30 يوماً لكل ملف) ← نستورد الخط الزمني كسجل للقراءة فقط.
   - **API المنافس** بمفتاح من إعداداته (Settings → API Keys): إن أتاح جلب الرسائل نستورد النص كاملاً — يُتحقَّق منه بمفتاح العميل قبل الوعد.
   - **فترة تداخل**: نضبط ويبهوك المنافس (Settings → Webhooks) ليمرّر كل رسالة جديدة إلينا حتى يوم النقل ← لا تضيع أي محادثة من الآن.
6. **يوم النقل**: نقل الرقم إلى تطبيقنا ← استيراد نهائي ← تشغيل الفلوهات ← مراقبة 48 ساعة.
