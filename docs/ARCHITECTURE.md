# 🏗️ البنية التقنية — BotYalla

## نظرة عامة
منصة SaaS لإنشاء وتشغيل بوتات تليجرام بدون كود، مع اشتراكات ودفع محلي.
**Python + Flask + SQLite + python-telegram-bot** — بلا اعتماديات ثقيلة.

## المكوّنات (الملفات)
| الملف | المسؤولية |
|---|---|
| `app.py` | خادم Flask — كل المسارات، الجلسات، CSRF، فرض الباقات |
| `database.py` | طبقة SQLite (users, bots, subscriptions, payments, events, platform...) |
| `auth.py` | تشفير كلمات المرور (Werkzeug) |
| `plans.py` | تعريف الباقات وحدودها |
| `payments.py` | محرك التحقق من الدفع (فحص الصورة، بصمة التكرار، OCR اختياري) |
| `platform_bot.py` | بوت المنصة — تنبيه الأدمن بأزرار موافقة/رفض |
| `bot_manager.py` | تشغيل عدة بوتات + بوت المنصة في حلقة asyncio بخيط منفصل |
| `flow_engine.py` | محرك المحادثات العام (No-Code) |
| `templates_bot.py` | قوالب البوتات: flow / store / booking / customer_service |
| `tg_helpers.py` | التحقق من التوكن + ربط الأدمن + أوامر مشتركة |
| `ai_agent.py` | وكيل الذكاء الاصطناعي (Gemini/Groq) + مولّد احتياطي |
| `i18n.py` / `icons.py` | الترجمة (عربي/إنجليزي) + مجموعة الأيقونات |

## نموذج البيانات (أهم الجداول)
- **users** — حسابات لوحة التحكم (كلمة مرور مشفّرة).
- **bots** — كل بوت: توكن، قالب، إعدادات JSON، حالة التشغيل، المالك.
- **subscriptions** — باقة المستخدم + تاريخ الانتهاء.
- **payments** — كل دفعة: طريقة، مبلغ، صورة، بصمة، نتيجة الفحص الآلي، الحالة (pending/approved/rejected).
- **platform** — إعدادات المنصة (بيانات الدفع، توكن بوت التنبيهات، معرّف المالك).
- **events** — أحداث للتحليلات (start/lead/order/booking).
- **bot_users** — مشتركو كل بوت (للبث الجماعي).

## تشغيل البوتات
`BotManager` يشغّل حلقة `asyncio` في **خيط منفصل** عن Flask. كل بوت `Application` مستقل يعمل بـ polling.
بوت المنصة يعمل بنفس الحلقة مع `CallbackQueryHandler` لأزرار الموافقة/الرفض.

> **قيد التوسّع:** الحالة في الذاكرة ⇒ عملية Gunicorn واحدة (`workers=1`). للتوسّع الأفقي:
> افصل مدير البوتات في خدمة مستقلة تتواصل مع الويب عبر قاعدة البيانات/طابور رسائل.

## تدفّق الدفع (التحقق المزدوج)
```
المستخدم يختار باقة → صفحة الدفع (QR + بيانات) → يدفع خارجياً → يرفع اسكرين
        │
        ▼
[طبقة 1: فحص آلي]  صورة صحيحة؟ + بصمة SHA-256 (تكرار؟) + OCR اختياري (المبلغ)
        │  (استشاري فقط — لا يفعّل شيئاً)
        ▼
[طبقة 2: بوت المنصة]  تنبيه للأدمن بالصورة + زرّي ✅/❌
        │
        ▼
موافقة الأدمن (هو فقط) → تفعيل الاشتراك 30 يوماً (ذرّي، غير قابل للتكرار)
```

## قابلية النقل لقاعدة بيانات أكبر
SQLite كافٍ لآلاف المستخدمين. للانتقال لـ PostgreSQL لاحقاً: طبقة `database.py` معزولة، فالتغيير محصور فيها.
