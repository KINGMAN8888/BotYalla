# 🚀 الرفع على Hostinger VPS (تلقائي)

## المطلوب
- **Hostinger VPS** بنظام **Ubuntu** (مش Shared Hosting — لازم VPS).
- بيانات الدخول: **IP السيرفر · اسم المستخدم (root) · كلمة المرور** (من لوحة Hostinger → VPS → SSH Access).
- **ويندوز 10 أو 11** (فيه `tar` مدمج).
- (اختياري) **دومين** موجّه لـ IP السيرفر (سجل A).

## الخطوات (دقيقتين)
1. افتح مجلد المشروع → مجلد **`deploy`**.
2. **دبل كليك على `deploy_hostinger.bat`**.
3. اكتب لما يطلب منك:
   - عنوان السيرفر (IP)
   - اسم المستخدم (غالباً `root`)
   - كلمة مرور السيرفر (مخفية أثناء الكتابة)
   - الدومين (أو اتركه فارغاً)
4. اضغط `y` للبدء — والسكربت يعمل الباقي **تلقائياً**:
   - يحمّل أدوات الاتصال (plink/pscp) أول مرة.
   - يضغط مشروعك ويرفعه للسيرفر.
   - يثبّت Python + Nginx + يجهّز البيئة والخدمة.
   - يشغّل الموقع بشكل دائم (يعيد التشغيل تلقائياً لو السيرفر اتقفل).

## بعد الرفع
- افتح `http://عنوان-السيرفر` (أو دومينك).
- سجّل دخول: **admin / admin1234** → غيّر كلمة المرور فوراً من «حسابي».
- من «إعدادات المنصة»: راجع بيانات الدفع وحط توكن بوت التنبيهات.

## تفعيل HTTPS (لو عندك دومين)
ادخل السيرفر عبر SSH وشغّل:
```bash
sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com
```

## التحديثات لاحقاً
عدّل ملفاتك محلياً، وشغّل `deploy_hostinger.bat` مرة أخرى — يرفع أحدث نسخة ويعيد التشغيل. (بياناتك وقاعدة البيانات على السيرفر تبقى سليمة.)

## ملاحظات
- لو كلمة مرور السيرفر فيها رموز غريبة مثل `!` أو `^` أو `%`، غيّرها لكلمة أبسط مؤقتاً من لوحة Hostinger.
- لو ظهرت رسالة أن plink/pscp لم يُحمّلا: نزّلهما يدوياً من putty.org وضعهما بجوار ملف `.bat`.
- لو معاك VPS جديد تماماً، السكربت يثبّت كل المتطلبات من الصفر.
