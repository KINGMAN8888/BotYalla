# 🔒 الأمان — BotYalla

ملخص الضوابط الأمنية المطبّقة والمؤكّدة بالاختبار.

## المصادقة والجلسات
- كلمات المرور مشفّرة بـ **Werkzeug PBKDF2** (لا تُخزَّن كنص).
- كوكيز الجلسة: **HttpOnly** + **SameSite=Lax** + **Secure** (على HTTPS عبر `COOKIE_SECURE=1`).
- **تحديد محاولات الدخول** (Rate limiting) لمنع التخمين.
- `FLASK_SECRET` عشوائي يُولَّد تلقائياً عند النشر.

## الحماية من الهجمات
| الهجوم | الحماية |
|---|---|
| **SQL Injection** | كل الاستعلامات تستخدم معاملات `?` — لا دمج نصوص إطلاقاً |
| **CSRF** | توكن CSRF في كل نموذج + في ترويسة كل طلب fetch؛ يُرفض أي POST بدونه (400) |
| **XSS** | Jinja يفلتر المخرجات تلقائياً (autoescape) |
| **Open Redirect** | مبدّل اللغة يعيد التوجيه لمسارات داخلية فقط |
| **رفع ملفات ضارة** | فحص الامتداد + التوقيع (magic bytes) + حد حجم 8MB + اسم ملف آمن |
| **تجاوز الصلاحيات** | كل بوت مقيّد بمالكه (404 للغير)؛ إعدادات المنصة للمالك فقط (403) |

## أمان الدفع (التحقق المزدوج)
- **لا تفعيل تلقائي إطلاقاً** — الاشتراك يُفعَّل فقط بموافقة الأدمن على تليجرام.
- **الأدمن فقط** (معرّفه المخزّن) يقدر يوافق/يرفض — أي حساب آخر يُرفض.
- الموافقة **ذرّية وغير قابلة للتكرار** (لا تفعيل مزدوج لنفس الدفعة).
- **المبلغ من جهة الخادم** (سعر الباقة) — لا يمكن للمستخدم التلاعب به.
- **كشف تكرار الإيصال** ببصمة SHA-256 (يمنع إعادة استخدام نفس الصورة).
- **صور الإيصالات خاصة** — غير متاحة عبر الويب، تُرسل للأدمن عبر تليجرام فقط.

## توصيات إضافية للإنتاج
- شغّل خلف **HTTPS** دائماً (Certbot مجاني).
- خذ **نسخة احتياطية** دورية من `botyalla.db` ومجلد `uploads/`.
- لا تشارك ملف `.env` أو قاعدة البيانات (تحوي توكنات البوتات).
- (مستقبلاً) تشفير توكنات البوتات في قاعدة البيانات، وإضافة سجل تدقيق كامل.

## نظام الأدوار (RBAC)
- **admin** (المالك): تحكّم كامل — لوحة الأدمن، إدارة المستخدمين والأدوار، الموافقة على المدفوعات، إعدادات المنصة.
- **support** (الدعم): مشاهدة لوحة الأدمن والمستخدمين والمدفوعات — **بدون** تغيير الأدوار أو إعدادات المنصة أو البتّ في المدفوعات.
- **user**: عميل عادي (بوتاته فقط).
- المستخدم رقم 1 (أنت) مقفول على دور admin ولا يمكن تخفيضه.
- المستخدم المحظور (is_blocked) لا يستطيع تسجيل الدخول.
