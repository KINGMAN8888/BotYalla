# الربط مع BotYalla — دليل الشريك التقني

> للشركة اللي عايزة تبعت وتستقبل واتساب من رقمها هي، من غير ما تتعامل مع Meta.
> **BotYalla مزوّد خدمة تقنية معتمد من Meta (Tech Provider)** — الربط بيتم من جوّه المنصة.

---

## اللي هتاخده

| | |
|---|---|
| `WHATSAPP_WABA_ID` | معرّف حساب واتساب بيزنس **باسمك انت** |
| `WHATSAPP_PHONE_NUMBER_ID` | معرّف رقمك |
| مفتاح BotYalla | بديل `WHATSAPP_ACCESS_TOKEN` — تبعت بيه، ونلغيه لوحده لو اتسرّب |
| رابط ويبهوك | تسجّله عندنا، ونبعتلك عليه كل رسالة داخلة |

**الرقم والحساب باسمك انت**، وفاتورة الرسايل على وسيلة دفعك في Meta مباشرة — تعريفة Meta بلا أي زيادة.

---

## الخطوات

### 1) اربط رقمك (٣ دقايق، مرة واحدة)

اعمل حساب على BotYalla ← **«اربط واتساب»** ← نافذة Meta تفتح ← اختار أو أنشئ حساب واتساب بيزنس ورقمك ← تمام.

مش هتفتح `developers.facebook.com`، ولا تعمل App، ولا System User، ولا تستنى مراجعة.

> **رقم شغّال دلوقتي على تطبيق WhatsApp Business؟** اختار **وضع التعايش** — الرقم يفضل شغال معاك على الموبايل، والبوت يشتغل عليه في نفس الوقت.

### 2) هات مفتاحك

**البوت ← الربط والمطوّرين ← مفتاح جديد.**

المفتاح **بيظهر مرة واحدة بس** — إحنا بنحفظ بصمته (HMAC) مش نصّه، فمحدش عندنا يقدر يقراه. ضاع؟ اعمل واحد جديد وألغِ القديم.

تقدر تخلّي المفتاح **مقصوراً على بوت واحد** — عشان مفتاح خادم واحد ما يبعتش من كل أرقامك.

### 3) ابعت

نفس بنية Cloud API حرفياً. **غيّر عنوان الأساس وبس**، وكودك يفضل زي ما هو:

```
https://graph.facebook.com/v21.0/{PHONE_NUMBER_ID}/messages   ←  قبل
https://botyalla.com/api/v1/{PHONE_NUMBER_ID}/messages        ←  بعد
```

```bash
curl -X POST 'https://botyalla.com/api/v1/{PHONE_NUMBER_ID}/messages' \
  -H 'Authorization: Bearer by_live_xxxxxxxx' \
  -H 'Content-Type: application/json' \
  -d '{"messaging_product":"whatsapp","to":"2010xxxxxxx",
       "type":"text","text":{"body":"أهلاً 👋"}}'
```

الرد بيرجعلك **زي ما Meta بتردّه بالظبط** — نفس `messages[].id` ونفس شكل الأخطاء. القوالب والوسائط والرسائل التفاعلية كلها بتمرّ بلا أي تعديل.

| الحالة | معناها |
|---|---|
| `401` بجسم فيه `"type":"auth"` | المفتاح غلط أو ملغى |
| `403` | المفتاح مش مسموح له بالرقم ده |
| `429` | تعدّيت ٦٠٠ نداء في الدقيقة |
| أي حالة تانية | **رد Meta نفسه** كما هو |

### 4) استقبل

**مهم:** ويبهوك Meta بيوصل لتطبيق BotYalla (إحنا المشتركين في الـWABA بتاعك)، فتطبيقك **مش هيستقبل من Meta مباشرة**. إحنا اللي بنمرّرهولك.

**البوت ← الربط والمطوّرين ← الاستقبال (ويبهوك)** ← حطّ عنوان خادمك (لازم `https` وعنوان عام).

هنبعتلك `POST` بـ**نفس جسم تحديث Meta حرفياً**، ومعاه توقيعنا:

```
X-BotYalla-Signature-256: sha256=<HMAC-SHA256(raw_body, your_secret)>
```

اتأكد من التوقيع قبل ما تثق في أي حاجة:

```python
import hmac, hashlib

def verify(raw_body: bytes, header: str, secret: str) -> bool:
    expected = "sha256=" + hmac.new(secret.encode(), raw_body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(header or "", expected)
```

```js
const crypto = require("crypto");
const verify = (raw, header, secret) =>
  crypto.timingSafeEqual(
    Buffer.from(header || ""),
    Buffer.from("sha256=" + crypto.createHmac("sha256", secret).update(raw).digest("hex")));
```

**اشتغل على الجسم الخام** قبل أي تحليل JSON — إعادة ترتيب المفاتيح بتكسر التوقيع.

ردّ بـ`200` بسرعة (مهلتنا ١٠ ثواني). **مفيش إعادة محاولة حالياً**: لو خادمك وقع أو اتأخر بنسجّل الفشل ونكمّل — الرسالة نفسها ما بتضيعش، بتفضل في صندوق BotYalla، بس نسختك مش هتتبعت تاني. محتاج ضمان تسليم؟ كلّمنا قبل ما تبني عليه.

## الفريق

الحساب مش شخص واحد. **الفريق ← رابط دعوة جديد** ← ابعت الرابط لموظفك ← يسجّل ويلاقي نفسه جوّه.

| الصلاحية | بيقدر يعمل إيه |
|---|---|
| **مدير** | كل حاجة + الفريق + المفاتيح والأسرار (بكلمة مروره هو) |
| **موظف** | البوتات والمحادثات — **ولا يشوف أي سرّ ولا يدير الفريق** |

الرابط بيظهر **مرة واحدة** وينتهي بعد ٧ أيام، وتقدر تلغيه في أي وقت.

## الأمان — إزاي بنتعامل مع أسرارك

- **توكن Meta عمره ما يخرج من خادمنا.** انت بتحمل مفتاحنا إحنا، فلو اتسرّب نلغيه وحده بلا ما نمسّ ربطك ولا بقية عملائنا.
- **الأسرار مش بتنزل مع الصفحة.** بتتطلب بنداء منفصل بعد ما تدخل كلمة مرورك، والنافذة بتتقفل بعد ١٥ دقيقة.
- **المفاتيح مش مخزّنة.** القاعدة فيها بصمة HMAC بس — ولا موظف عندنا يقدر يقرا مفتاحك.
- **ويبهوكك لازم `https` وعنوان عام** — بنرفض العناوين الداخلية و`localhost` عمداً.
- **ما تبعتش أي مفتاح أو توكن في شات ولا إيميل.** كل حاجة بتظهر في لوحتك وبس.

## حدود لازم تعرفها من دلوقتي

- **نافذة الـ٢٤ ساعة**: بعد ٢٤ ساعة من آخر رسالة من العميل، مينفعش تبعتله غير **قالب معتمد** من Meta. ده شرط Meta مش شرطنا.
- **٦٠٠ نداء في الدقيقة** لكل مفتاح. محتاج أكتر؟ كلّمنا.
- **٢٠ مفتاح** و**٥٠ عضو فريق** لكل حساب.
- **تكلفة الرسايل** على وسيلة دفعك في Meta — [أسعار Meta الرسمية](https://developers.facebook.com/docs/whatsapp/pricing).

## أسئلة بتتكرر

**ينفع أستخدم رقم BotYalla بدل رقمي؟**
لأ. رسايلك هتطلع من رقمنا، فأي بلاغ سبام يضرب تقييم الرقم ويأثر على كل عملائنا — وده مخالف لشروط Meta كمان. رقمك انت أأمن ليك وليّنا.

**ينفع آخد `WHATSAPP_ACCESS_TOKEN` نفسه؟**
لو **بتبعت وبس**، ينفع نعرضهولك من صفحة المطوّر. بس ساعتها مسؤولية حمايته عليك، ومش هنقدر نلغيه لوحده. المفتاح أحسن في كل الحالات.

**لو غيّرت سرّ الويبهوك؟**
التوقيع القديم يقف فوراً. غيّره على خادمك قبل ما تدوس «تغيير السرّ».

**بوت BotYalla والـAPI بتوعي — مش هيتخانقوا؟**
لأ. الرسالة بتتعالج عندنا **وبتتبعتلك نسخة منها** في نفس الوقت. عايز تتحكم انت بالكامل؟ اقفل البوت من لوحتك وخلّي الويبهوك شغال.
